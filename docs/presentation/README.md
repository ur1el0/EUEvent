# EUEvent Presentation Guide

The team considers the agreed MVP feature scope complete. These guides explain the current implementation and demonstrate its behavior accurately. A finished feature scope is different from production certification: deployment, mail, PostgreSQL concurrency, accessibility, and venue-specific rehearsal still need recorded evidence.

## Guides

1. [Live demo run of show](01-live-demo-run-of-show.md) — prepare the local environment and present the administrator, student, and staff flows.
2. [How the system works](02-how-the-system-works.md) — explain the architecture, ticket proof, offline queue, and reconciliation.
3. [Post-MVP operational follow-up](03-post-mvp-operational-follow-up.md) — list environment and venue-readiness checks without treating them as missing product features.
4. [Presenter explanation notes](04-presenter-explanation-notes.md) — answer common questions without overstating the guarantees.

The implementation is considered complete for the agreed scope. The event-day runbook remains the operating guide for stale manifests, offline event changes, scanner replacement, and manual exceptions. Record any physical rehearsal separately; a passing automated check or a built APK is not evidence that every venue scenario has been exercised.
